## Why I built this

The main goal of this project was to build a **live operating system for myself**, something I could actually use to manage my everyday life.

But there was another big reason. I wanted to improve my Python before I go to my favourate field which is AI.

While making DeskOS, I learned a lot about Python, including Tkinter for building the UI, SQLite for storing data, working with modules, functions, databases and connecting different parts of an application.

It was challenging, but I learned way more by actually building it and I can say its a pretty cool project(atleast for me)

## Features

- **Dashboard:** A quick overview of your overall productivity.
- **Tasks:** Add, edit, complete and delete tasks.
- **Finance:** Keep track of income and expenses.
- **Habits:** Track daily habits with crudd.
- **Notes:** Save and organise important notes.
- **Journal:** Write and manage daily journal entries.
- **Global Search:** Search across different sections of the app.

## Built With

- **Python :** Main programming language.
- **Tkinter:** Desktop user interface.
- **SQLite:** Local database.
- **Git and GitHub:** Version control.

## Running DeskOS

You need Python 3 installed on your computer.

1. Clone this repository:

   ```bash
   git clone https://github.com/TheWolves86/DeskOS.git
   ```

2. Open the project folder:

   ```bash
   cd DeskOS
   ```

3. Run the application:

   ```bash
   python main.py
   ```

That's it! The database is stored locally, so your data stays on your computer.
